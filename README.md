# Ultimate Asistan (Mobil)

ULTIMATE ekosisteminin Flutter tabanlı mobil uygulaması. Notlar, takvim, müzik çalar ve kariyer modüllerini tek uygulamada birleştirir.

## Özellikler

- **Notlar:** hızlı not oluşturma, Kotlin MethodChannel ile bildirim/paylaşım üzerinden kayıt
- **Takvim:** günlük plan ve etkinlik görünümü
- **Müzik:** yerel kütüphane, çalma listeleri, oynatıcı, ekolayzer ve MIDI desteği
- **Kariyer:** GitHub tabanlı CV verisi ve senkronizasyon
- **Senkronizasyon:** Supabase ile kimlik doğrulama ve cihazlar arası veri senkronizasyonu; çevrimdışı önbellek

## Teknoloji

Flutter / Dart, Kotlin (Android native katmanı), Supabase Flutter, shared_preferences, just_audio, connectivity_plus.
